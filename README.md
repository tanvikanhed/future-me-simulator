#  Future Me Simulator

A web-based habit simulation application that helps users understand how their current daily habits may influence their future progress.

##  Problem Statement

People often track daily habits such as study time, sleep, exercise, screen time, and consistency, but they may not understand how their current habits could affect their future progress.

The **Future Me Simulator** analyzes a user's current habits and generates simulated future trajectories under different scenarios, helping users visualize the possible impact of their daily choices.

##  Features

-  Habit-based progress scoring
-  30, 90, and 180-day future projections
-  Current Me, Better Me, and Ideal Me scenarios
-  Interactive future progress graph
-  Personalized habit insights
-  What-If habit simulation
-  Responsive interface
-  Deployed and accessible across devices

##  How It Works

User enters daily habits
        ↓
JavaScript collects the input
        ↓
Data is sent to Flask API
        ↓
Python calculates the habit score
        ↓
Future scenarios are generated
        ↓
Results are returned to JavaScript
        ↓
Chart.js visualizes future progress
        ↓
Personalized insights are displayed
